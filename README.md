## 簡介

放射腫瘤科醫師出國或休假前，用來整理治療中病人的交班單。
線上頁面是**空白範本**（不含任何病人資料），醫師在瀏覽器中新增病人、填寫交班資訊，
完成後「另存鎖定版」產生一份**唯讀、無程式碼**的 HTML 檔存到自己電腦，寄給代理醫師直接開。

## 零個資部署架構

```
GitHub Pages（公開）        瀏覽器（本機）              鎖定版檔案（本機/Email）
┌──────────────┐    開啟    ┌──────────────┐   另存    ┌──────────────┐
│  空白範本      │ ────────→ │  新增病人填寫  │ ────────→ │  唯讀快照      │
│  無任何病人資料 │           │  資料不上傳    │           │  無 script    │
└──────────────┘           └──────────────┘           └──────────────┘
```

- 部署的頁面永遠是空白範本，**repo 內沒有、也絕不能有病人資料**
- 填寫過程全在瀏覽器記憶體，關閉分頁即消失，不經過任何伺服器
- 鎖定版檔名 `交班單_鎖定版_YYYYMMDD.html` 已列入 `.gitignore`，防止誤 commit

## 部署（GitHub Pages）

1. 用 Git Pusher 匯入本 zip，推送到 GitHub repo（**repo 設 Public**，免費方案 Pages 需公開 repo）
2. Repo → Settings → Pages → Source：Deploy from a branch → `main`，資料夾 `/ (root)`
3. 等 1–2 分鐘，連結出現在 Settings → Pages（形如 `https://sela1227.github.io/<repo>/`）
4. 後續改版：推 main 即自動重新部署

本機使用也完全可行：直接開 `index.html` 即可，功能相同。

## 使用

1. **新增病人**：「＋ 新增病人」建立卡片，姓名、病歷號點擊填寫，癌別下拉選擇
2. **治療參數**:預定次數、單次劑量、已完成次數可修改；剩餘次數與累計劑量自動計算，剩餘 ≤ 5 次標示「即將完成」
3. **副作用**：下拉選單（皮膚炎／黏膜炎分級等 16 項）＋下方補充說明手寫欄
4. **輸出**：「列印」精簡版面；「🔒 另存已填寫版本（鎖定）」產生唯讀 HTML——所有欄位轉為純文字、移除全部按鈕與程式碼，僅保留列印功能
